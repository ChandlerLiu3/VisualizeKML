# VisualizeKML
在三维空间中观看轨迹，掌握路线的高低俯仰之势。

当前版本：**0.2.0**。在基础轨迹查看之外，可提取 KML `Point` 标记，推断缺失的起点/终点，
并从轨迹高程剖面标出最高点及峰顶、垭口、谷底候选。

## 运行

需要安装 Rust stable 工具链和可用的桌面图形环境。

```powershell
cargo run --release
```

启动时会弹出 KML 文件选择框；也可以直接传入文件路径：

```powershell
cargo run --release -- "D:\path\to\track.kml"
```

窗口中按 `Ctrl+O` 可加载其他 KML 文件。鼠标左键拖动可旋转视角，滚轮可缩放。
场景中的标记标签和“轨迹标记”列表会显示标记类别、名称、海拔及其来源；列表空间有限时只列出前 14 个，
其余仍显示在场景中。推断的地貌会明确标为“候选”。
若轨迹不含有效海拔，会显示提示且不生成高程地貌标记。描述、样式引用和扩展数据会被解析保留，
但不会加载描述中的远程图片或链接。中文标签使用系统已安装的中文字体。

支持 `LineString`/`MultiGeometry` 的 `coordinates` 和 Google 扩展的 `gx:Track/gx:coord`。
自动地貌候选使用 30 米显著性阈值及 500 米最小间距，以过滤常见高程噪声；它们只代表轨迹剖面上的候选，
不等同于经地形数据确认的真实山峰或垭口。在线地图、海拔冷暖渐变、H 键快捷操作、右键平移、
轨迹动画和 KML 样式渲染仍属于后续版本范围。
